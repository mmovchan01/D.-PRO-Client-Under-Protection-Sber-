# Ноутбуки: проект для новичка за 7 шагов

Ноутбуки идут по порядку — от «запусти за 5 минут» до «пойми, почему победил CatBoost».
В каждом: объяснения простыми словами + код с комментарием к каждой строке.

| № | Ноутбук | О чём | Время |
| --- | --- | --- | --- |
| 00 | `00_quickstart.ipynb` | Быстрый старт: окружение, данные одним взглядом, готовое предсказание | 5 мин |
| 01 | `01_data_overview.ipynb` | Смотрим на CSV глазами: колонки, типы, цель, пропуски, проверки | 15 мин |
| 02 | `02_eda.ipynb` | Графики: распределение цели, корреляции, группы, согласованность | 20 мин |
| 03 | `03_feature_engineering.ipynb` | Новые признаки + заполнение пропусков + стандартизация (самая важная механика!) | 25 мин |
| 04 | `04_train_catboost.ipynb` | Обучение: бустинг, фолды, OOF, RMSE, важности признаков | 25 мин |
| 05 | `05_predict_submission.ipynb` | Предсказание изнутри: ансамбль, обрезка, проверки submission | 20 мин |
| 06 | `06_experiments.ipynb` | Сравнение моделей и главный секрет: OOF 10.4 vs лидерборд 71.21 | 20 мин |

## Как открыть

Вариант 1 — VS Code: открой папку проекта, кликни по `.ipynb`, выбери Python с установленными
зависимостями (`python -m pip install -r requirements.txt`).

Вариант 2 — Jupyter:

```bash
python -m pip install -r requirements.txt
python -m jupyter lab  # или: python -m notebook
```

и открой любой файл из `notebooks/`.

## Правила ноутбуков

- Первая ячейка каждого ноутбука сама переходит в корень проекта — запускай ячейки по порядку сверху вниз.
- Ноутбуки ничего не портят: демо-модели обучаются в памяти, файлы пишутся только в `/tmp/`.
  Папка `artifacts/` (настоящие веса) ноутбуками не изменяется.
- Тяжёлые полные прогоны (`train.py` целиком, `experiments.py`) в ноутбуках не запускаются —
  там даны команды для терминала.
