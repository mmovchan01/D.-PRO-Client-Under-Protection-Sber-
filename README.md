# D. PRO: Клиент под защитой (Сбер)

Решение задачи регрессии для предсказания `protection_score` (RuCode 2026, «Лига Профессионалов»).

## Итог и честная оценка качества

- Финальная модель: сигмоидально-линейный индекс, обученный непосредственно по MSE на шкале 0–100.
  ```text
  protection_score = 100 * sigmoid(intercept + standardized_numeric_features @ coefficients)
  ```
- Out-of-fold RMSE на `hard_train.csv` (5-fold, все данные для подбора — только train): **10.18** (seed 434089, см. `artifacts/model_metadata.json`), 10.16 при seed 42 в `experiments.py`.
- **Порог RMSE 7 (0 баллов по условию) не достигнут.** По условиям задачи текущее решение получит 0 баллов.
- Причина установлена анализом (см. `reports/eda/eda_summary.md`): целевая переменная ведёт себя как `100·sigmoid(линейный индекс + N(0, ~0.6))`. Остатки на логит-шкале нормальные и однородные (std ≈ 0.6 в каждом децile), а на шкале 0–100 сильно гетероскедастичны. Шум 0.6 в логитах даёт RMSE около 10.4 даже при идеально известном индексе. Чтобы получить RMSE 7, шум должен быть около 0.4.
- Все проверенные модели (линейные, сплайны, взаимодействия, категории, LightGBM, MLP) дают 10.15–10.8 (`reports/experiments.md`). Двенадцать гипотез о скрытой структуре (производные признаки, локальность, взаимодействия, отношения доходов, пороги, гетероскедастичность, сдвиг train/test, функция связи, хвост по доходу, дробная логистическая регрессия, коллинеарность агрегата) не дали улучшения на шкале 0–100 (`reports/hypotheses.md`).

## Установка и запуск

Проверенная среда: Python 3.11.2.

```bash
python -m pip install -r requirements.txt
# для EDA и экспериментов дополнительно:
python -m pip install -r requirements-dev.txt
```

Обучение (seed выбирается случайно, будет напечатан):

```bash
python train.py --train-csv hard_train.csv --model-dir artifacts
```

Для воспроизведения конкретного прогона можно передать seed явно: `--seed 434089`.

Предсказание без обучения (создаёт `submission_seed_{SEED}.csv` по seed из метаданных):

```bash
python predict.py --input-csv hard_test.csv --model-dir artifacts
```

Для закрытого тестового набора передайте его путь в `--input-csv`.

EDA и эксперименты (необязательны для предсказания):

```bash
python eda.py --train-csv hard_train.csv --test-csv hard_test.csv --output-dir reports/eda
python experiments.py --train-csv hard_train.csv --output reports/experiments.md
```

## Данные: ключевые наблюдения EDA

- Пропуски: `house_value` (~47%), `car_value` (~41%), `average_claim_cost` (~40%). Это не совпадает с описанием задачи (~62% и ~58%), поэтому признаки следует считать по фактическим данным.
- Согласованность признаков: `insurance_products` равен сумме 8 страховых флагов, `average_claim_cost` пропущен ровно тогда, когда `number_of_claims = 0`, `claim_frequency = claims / years` в 100% строк (с округлением до 4 знаков), `wealth_segment` соответствует диапазонам дохода.
- Сильнее всего связаны с целью: `insurance_products` (r = 0.58), `active_policies`, `digital_behavior_score`, `cyber_protection`, `mobile_app_usage`, `internet_activity`.
- Категориальные признаки дают заметные различия средних (например, `business_owner` 78 против `unemployed` 62), но при наличии числовых признаков не улучшают модель.
- Дубликатов и утечек между train и test не найдено; порядок и ID клиента не несут сигнала (автокорреляция остатков около 0).

## Файлы

- `train.py` — подготовка признаков, проверка на holdout и 5-fold OOF, обучение финальной модели на всём train, сохранение весов.
- `predict.py` — загрузка весов, предсказание, запись submission.
- `model_utils.py` — общие функции: выбор числовых признаков, медианное заполнение пропусков, стандартизация, преобразования логит/сигмоида.
- `eda.py` — EDA: пропуски, распределения, корреляции, проверка согласованности, диагностика шума целевой переменной.
- `experiments.py` — сравнение моделей на одинаковых фолдах.
- `hypotheses.py` — проверка гипотез о скрытой структуре в данных (`reports/hypotheses.md`).
- `artifacts/` — веса, метаданные (seed, версии, признаки, метрики), коэффициенты.
- `reports/` — результаты EDA и экспериментов; `reports/data_audit.md` — аудит пропусков и устойчивость предсказания.
- `submission_seed_{SEED}.csv` — предсказания для открытого тестового набора.
