# D.-PRO-Client-Under-Protection-Sber-

Регрессия уровня страховой защиты клиента (`protection_score`, 0–100), метрика RMSE.

## Структура

| Файл | Назначение |
|---|---|
| `model.py` | Предобработка признаков и модель (общий код для train/predict) |
| `train.py` | Полное обучение на `hard_train.csv`, сохранение весов в `weights/` |
| `predict.py` | Предсказание на `hard_test.csv` без обучения, формирует `submission_seed_{SEED}.csv` |
| `weights/` | Веса модели, параметры препроцессинга, SEED обучения |
| `requirements.txt` | Библиотеки и версии |
| `submission_seed_{SEED}.csv` | Предсказания на открытом тестовом наборе |

## Модель

Признаки: индикаторы пропусков (`house_value`, `car_value`, `credit_score`, …), сумма страховых продуктов `ins_sum`, one-hot категориальных признаков, стандартизация.

Модель: `protection_score ≈ 100 · sigmoid(X·w + b)`, обучается напрямую по MSE с L2-регуляризацией (λ = 1e-3). Структура подобрана по данным: цель ограничена 0–100 и насыщается у верхней границы, линейная модель без сигмоиды даёт RMSE 11.5, сигмоидная — 10.2.

Бэггинг: 30 моделей, обученных на bootstrap-выборках, предсказания усредняются. Всё случайное управляется SEED.

Оценка: 5-fold CV RMSE ≈ **10.20** (на обучающих данных, тестовые выборки не использовались).

Сравнивались и не дали выигрыша: LightGBM (10.48), CatBoost (10.36), смесь CatBoost + сигмоидная модель (10.18 при весе 0.8), сплайны (10.34+), парные взаимодействия (10.24).

## Воспроизведение

```bash
pip install -r requirements.txt

# обучение (SEED выбирается случайно и печатается; либо задайте --seed)
python train.py --seed 732805   # --cv — дополнительно CV RMSE

# предсказания (SEED берётся из weights/meta.json)
python predict.py
```

Результат: `submission_seed_732805.csv` (столбцы `customer_id`, `protection_score`).
